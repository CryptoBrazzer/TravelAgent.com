# AI Travel Agent — GitHub Pages

Готовый статический сайт без сборки и зависимостей.

## Публикация
1. Создайте новый GitHub repository.
2. Загрузите всё содержимое этой папки в корень repository.
3. GitHub → Settings → Pages.
4. Source: **Deploy from a branch**.
5. Branch: **main**, folder: **/(root)** → Save.
6. Через несколько минут GitHub покажет публичный URL.

## Структура
- `index.html` — сайт
- `style.css` — дизайн, адаптивность и анимации
- `script.js` — RU / UA / EN и динамика
- `assets/` — визуалы
