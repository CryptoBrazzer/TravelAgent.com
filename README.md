# ESCAPE — AI Travel Agent website v3

Production-ready static website package for `escapetravel.site`.

## Improvements in v3
- Updated travel market data to 2025/2026 sources.
- Transparent animated “Travel Pulse”: an estimate based on 1.52B international tourist arrivals in 2025, not a fake Booking.com live feed.
- Animated regional travel chart (Europe 793M, Asia-Pacific 331M, Americas 218M, Middle East ~100M, Africa 81M).
- Added motion layer, route animation, decision-engine visualization and reduced-motion accessibility.
- Privacy Policy, Terms, Cookie Policy and AI & Travel Disclaimer now switch between RU / UA / EN.
- Existing product, EV, Paris, Amsterdam, weekend and community visuals retained.
- No investor ask on the public website.

## Data sources
- UN Tourism, January 2026: 1.52B international tourist arrivals in 2025; +4% YoY; 2026 outlook +3–4%.
- UN Tourism regional 2025 arrivals: Europe 793M, Asia-Pacific 331M, Americas 218M, Middle East ~100M, Africa 81M.
- WTTC, August 2026: Travel & Tourism contributed $11.6T to global GDP in 2025.
- IEA Global EV Outlook 2026: electric-car sales exceeded 20M globally in 2025.

## Deployment
Upload/commit the contents of this folder to the existing GitHub repository connected to Vercel. Vercel should redeploy automatically.

## Important
The live counter is explicitly a statistical model derived from an annual baseline. It is not a real-time booking feed and does not claim access to Booking.com transaction data.

Legal pages are tailored to the current pre-launch website. Review with qualified counsel before commercial launch, especially before adding accounts, payments, booking, precise location, user-generated content or community matching.
